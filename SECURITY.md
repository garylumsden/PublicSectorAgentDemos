# Security policy

## Supported version

Security updates apply to the latest commit on `main`.

## Report a vulnerability

Do not create a public issue for a suspected vulnerability.
Use GitHub private vulnerability reporting for this repository.
Include the affected component, reproduction steps, impact, and any suggested mitigation.

Do not include credentials, access tokens, customer data, or production identifiers in the report.

## Demonstration scope

This repository contains demonstration software and synthetic data.
It is not a production service template.
Review identity, network, data, monitoring, resilience, and operational controls before production use.
